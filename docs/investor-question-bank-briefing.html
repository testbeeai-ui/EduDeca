What sort_order means

Same column name. Completely different job.

Present Proposed
sort_order is The set / paper number (1 to 20) The item number inside one discipline (1 to 20–30)
If the number is 7 Load mixed set 7: Physics-7 + Chemistry-7 + Analytical-7 + … all together Physics item #7 in the Physics pool only. Chemistry #7 is a different row, not the same paper
Who shares that number All 12 subjects share set 7 Nobody shares it. Each pool counts 1, 2, 3… on its own
Start Challenge uses it to WHERE level = 1 AND sort_order = 7 → whole set Does not pick a set. Picks 1 unused row per discipline, any remaining numbers

Present · sort_order = 7

One mixed set. Every subject uses 7.

Proposed · sort_order = 7

Three separate pools. 7 is only a slot inside that pool.

iddiscipline_idsort_orderMeans
l1-phy-007phy77th Physics question in the Physics bank
l1-che-007che77th Chemistry question — not tied to Physics 7
l1-log-007log77th Analytical question — not tied to Physics 7

A round might take Physics 3, Chemistry 19, Analytical 7. The numbers do not have to match.

10 tries — how an attempt is counted

Fail used Tries left

Example: 3 fails used, 7 left. 10th fail closes the level. Spare questions in the pool do not add an 11th try.

Pass No fail used

Question still marked seen

Fail round +1 try used

Every finished card is seen

Quit mid-round No fail used

Only answered cards are seen

Skip a card No extra try

That card is still never repeated
